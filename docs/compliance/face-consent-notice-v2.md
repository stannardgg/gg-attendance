# 人脸信息采集与使用告知（同意书 v2）

- 版本：**v2**（生效日期：2026-11-23；v1 为勾选框时代的初版文本，本版按 PIPL §29「单独同意」要求重写，并明确保留期限与删除方式）
- 适用对象：本系统全部学生用户
- 使用位置：移动端「人脸采集」页底部弹窗全文展示；学生必须阅读全文并点击「同意并开始采集」才算完成单独同意（勾选框、静默继续、与其他协议捆绑勾选均不构成）
- 服务端校验：同意事件落 `face_consent_record`（事件流，只增不改），`account.face_consent_at / face_consent_version` 保留当前态；版本号由前端 `EnrollView.CONSENT_VERSION` 与后端 `FaceEnrollService.CONSENT_VERSION_CURRENT` 双侧持有，升版须同步

## 一、我们是谁、如何联系我们

本系统（人脸考勤系统）由 **【学校名称】**（以下称"学校"）运营。学校是你人脸信息的**个人信息处理者**，决定处理目的与方式，并对处理活动承担法律责任。系统开发与运维方按委托合同仅为学校提供技术支持，不独立使用你的人脸信息。

个人信息保护相关问题，请联系学校负责人：【负责人姓名 / 部门 / 联系方式】。

## 二、为什么处理你的人脸信息（目的与方式）

**唯一目的：课程签到的身份核验。** 具体包括：

1. 你在采集页主动拍摄样本，建立本人识别档案；
2. 你发起签到时，系统进行**活体检测**与**人脸比对**（本人 1:1 核验 / 现场抓拍与档案的 1:N 识别），判定"是你本人在签到"。

除此之外无任何其他用途：**不用于考勤以外的评价、不用于广告、不对外提供、不用于任何模型训练或商业用途。**

## 三、处理哪些信息

| 信息项 | 说明 | 是否保存 |
|---|---|---|
| 相机画面（人脸图像） | 采集与签到时摄像头看到的画面 | **不保存**。画面只在内存中完成质量检测与特征提取后即刻丢弃，全程不落盘 |
| 人脸特征向量 | 从画面提取的 512 维数值向量，不可逆推出原图 | **加密保存**（AES-256-GCM 字段级加密，密钥与数据分离保管） |
| 质量参数 | 清晰度、亮度、姿态角度等数值 | 保存（与向量关联，用于质检） |
| 采集/同意/审核时间与状态 | 何时采集、何时同意、审核结果 | 保存 |
| 签到核验结果 | 每次签到的时间与结果记录 | 保存（属考勤记录，见下条） |

微信内置浏览器因技术限制无法安全调用摄像头，系统在微信内直接禁止采集与签到拍摄。

## 四、保留多久（保留期限）

| 数据 | 保留期限 |
|---|---|
| 相机画面（原始图像） | 不保留（内存即时处理，处理完即丢弃） |
| 采集过程临时缓存（样本中转） | **15 分钟**自动销毁 |
| 活体检测挑战状态 | 会话级缓存，约 1 分钟自动销毁 |
| 人脸特征向量与档案状态 | **到你撤回同意、行使删除权，或因毕业/离校/归档等学籍异动被清除为止**；无固定到期日之外的其他用途续期 |
| 历史签到与考勤记录 | 属考勤业务数据（非人脸信息），按学校学籍与教学管理制度保留，不随人脸数据删除而清除 |
| 操作与访问审计日志 | 365 天，到期自动清理 |
| 系统问答留痕（AI 助手） | 180 天，到期自动清理 |
| 数据库备份 | 加密保存，滚动保留 7 天 |

## 五、你怎么删除、怎么撤回同意（删除权与撤回权）

1. **自助删除**：移动端「人脸采集」页底部有**「删除我的人脸数据并撤回同意」**按钮，一键物理删除你的全部人脸向量与档案，并撤回采集同意，**不需要审批、不需要联系老师**；
2. **撤回的效力**：撤回后系统立即停止对你的人脸处理（识别档案即时失效）；**撤回不影响撤回前已经产生的签到与考勤记录**；
3. **删除后的影响**：删除后你将无法使用人脸签到，如课程要求人脸签到，需要重新阅读本告知、重新同意并重新采集；
4. **辅助渠道**：你也可以联系老师或【负责人联系方式】代为处理删除请求；
5. 学籍异动（毕业、离校、归档）时，学校会同步清除你的人脸数据。

## 六、我们如何保护你的人脸信息

- **加密存储**：人脸向量采用 AES-256-GCM 在应用层逐条加密后入库，数据库文件、备份均不可直接读出人脸信息；备份文件单独加密（与数据库使用不同密钥）；
- **原图不落盘**：从架构上消除"照片泄露"面——原始画面从不写磁盘；
- **权限最小化**：按角色与数据范围授权，教师仅能查看所授权班级/课程的学生样本（审核用途），学生只能访问本人数据；向量接口仅限服务间内部调用；
- **全程留痕**：采集、同意、审核、删除均写入审计日志；
- **传输加密**：线上部署经 HTTPS。

## 七、不同意会怎样

人脸签到是可选能力。不同意本告知（不点「同意并开始采集」）将**无法使用人脸签到**，页面会立即退出且不打开摄像头、不保存任何数据；你可以请老师采用人工核对等替代方式完成考勤。你与学校之间的其他教学服务不因拒绝而受任何影响。

## 八、单独同意的效力说明

人脸信息属于**敏感个人信息**，处理它需要你的**单独同意**——即你针对"采集人脸用于签到"这一事项本身、在阅读本全文后做出的明确同意。本同意：

- 不与《用户协议》等其他条款捆绑；
- 按版本管理（当前 v2）；文本实质变更时会升版并请你重新同意；
- 同意时间与版本号由系统记录，可应你的要求向你出示。

## 九、争议与投诉

如你认为学校对你人脸信息的处理侵害了你的权益，可通过【负责人联系方式】投诉，学校将在 15 个工作日内答复；你也可以依据《个人信息保护法》向网信部门投诉举报。
