# CR-027 · 开课教师同步授权（课程管理的教师授予 = 教师授权的授予）

- 提出人：主人（2026-11-23 会话内指示「课程管理处的教师授予等同于教师授权处的授予功能，选择教师后应该同步给数据库教师端」）
- 提出日期：2026-11-23
- 状态：✅ **已批准并实现**
- 关联：§3.1（数据范围）/ §5.3.1（课程）/ §8.3 / §8.4.2 / §10 / §13.1；CR-026（课程授权学生，同属授权表家族）
- 影响工作包：WP-01（组织主数据）、WP-10（管理端前端）、WP-13（IT）

## 1. 问题

CR-027 之前，`course.owner_teacher_id`（开课教师）是纯归属标注：选了张三，
张三在教师端**依然看不到**这门课，必须再去「教师与授权 → 授权范围」手动
加一条 COURSE 授权。两处入口语义割裂，验收时反复踩坑（表单里明明选了教师，
教师端列表却是空的）。

## 2. 方案

### 2.1 同步规则（`CourseService`）

| 场景 | 行为 |
|---|---|
| 管理员建课带 `ownerTeacherId` | 插入 `teacher_scope(teacherId, COURSE, courseId)`，审计 `SCOPE_GRANT`（备注「开课教师同步授权」） |
| 管理员改课写 `ownerTeacherId` | 同上，**幂等**：同三元组已存在则跳过（重复保存不报错）；`null` = 不改（部分更新口径），清空 owner 不在此撤销 |
| owner 指向不存在的教师 | `FA-2001` 拒绝（owner 现在驱动授权，不允许留下指向幽灵教师的授权行）；`@Transactional` 保证连 owner 字段一起回滚 |
| TEACHER 建课 | owner 强制为本人（与 Agent `apply_owner_teacher` 同口径），**产生授权**——建课人登录即见自己的课 |
| TEACHER 改课 | owner 仍落为本人（沿用现状，预览不撒谎），但**不产生授权**——教师只能动授权范围内的课程，不构成新的授权来源，改课不能拿授权 |

### 2.2 撤销与既有授权的关系

- 撤销**只在**「教师与授权 → 授权范围」抽屉里做（与普通授权同一张表、
  同一个撤销按钮）；改 owner **不**自动撤销旧 owner 的授权（可能是历史
  手动授权，保留比静默删安全），需要时在抽屉里手动撤；
- 同步产生的授权与手动授权无差别：抽屉里同样可见、可撤；再次保存课程
  （owner 不变）幂等补投，撤了又想给回来也可以重新保存一次课程。

### 2.3 前端（提示文案两处）

- 课程表单「开课教师」：`仅作归属标注，不等于数据授权…` →
  `保存后自动为该教师授予本课程的数据权限（等同「教师与授权 → 授权范围」的授予，教师端立即可见）；撤销请到授权范围中操作`；
- 授权范围抽屉：改为「课程的开课教师保存时会自动在这里生成授权（CR-027），可在此撤销；班级负责教师仅是归属标注」。

## 4. 风险与补偿控制

| 风险 | 评估 | 补偿 |
|---|---|---|
| TEACHER 通过 REST 改任意课程 owner 为自己拿授权（update 无 @DataScope，历史面上教师本就能改任意课程） | **低**（新增面）：教师改课路径不产生授权（仅归属标注），授权只能由管理员通道写入 | 见 §2.1 表；审计 `COURSE_UPDATE` 留痕 |
| 改 owner 后旧 owner 仍能看到课程，业主以为自动收回 | 低 | §2.2 明确：撤销收口在授权范围抽屉；抽屉提示写明「自动生成、可撤销」 |
| 重复保存撞唯一约束 | 低 | 幂等跳过（先查后插，与 `ScopeService.grant` 同风格） |
| owner 清空（前端传 null）实际是"不改"，业主以为已清 | 低 | 部分更新口径既有约定（null=不改）；如需真正清空+撤权，后续单独立项 |

## 5. 验收口径

1. 管理员建课带开课教师 A → A 登录教师端，课程列表**立即可见**该课程；
2. 管理员重复编辑该课程（owner 不变）→ 200，不报"该授权已存在"；
3. owner 写成不存在的教师 ID → `FA-2001`（404），且课程 owner 字段不被改写；
4. 管理员把 owner 从 A 改成 B → B 立即可见；A 的授权保留，可在授权范围抽屉撤销；
5. TEACHER 建课 → owner=本人且自见；TEACHER 改课 → 不产生新授权；
6. 「授权范围」抽屉能看到同步生成的授权行（授权时间=保存课程的时间）。

（1~5 已由 `OrgIT.ownerTeacherSyncsScope` 覆盖，本机 12/12 通过。）
