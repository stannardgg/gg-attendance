# 架构决策记录（ADR）

记录**为什么这么选**，以及**试过但没选的方案**。结论写在 `项目文档.md`，过程写在这里。

## 什么时候写

- 选了某个技术方案，存在合理替代品（如"为什么用轮询不用 WebSocket"）
- 否决了某个方案，且否决理由是实测数据（如"为什么砍掉眨眼动作"）
- 改了契约的字段、枚举、阈值

**只写结论的 ADR 没有价值**。至少要包含"试过什么、用什么数据、得到什么数字、为什么放弃"。

## 命名

```
docs/adr/NNN-<短横线标题>.md      # 例：003-动作库只保留张嘴.md
```

编号三位递增，不复用，不删除（被推翻时新增一条并标注 `Supersedes`）。

## 模板

```markdown
# NNN. <决策标题>

- 日期：YYYY-MM-DD
- 状态：提议 / 已采纳 / 已废弃（被 NNN 取代）
- 相关：WP-xx、项目文档 §x.y

## 背景

现在的约束是什么？不解决会怎样？

## 候选方案

| 方案 | 优点 | 代价 |
|---|---|---|
| A | | |
| B | | |

## 实测数据

（若有）用哪个脚本、多少样本、得到什么数字。

## 结论

选哪个，为什么。

## 后果

- 正面：
- 负面：（接受了什么代价）
```
