## 2. 服务与端口

| 服务 | 镜像 | 宿主端口 | 说明 |
|---|---|---|---|
| nginx | `fa/web:1.0.0` | 80 / 443 | **唯一**对外入口 |
| java | `fa/java:1.0.0` | 无 | `/api/**` 经 nginx，`/internal/**` 只在内网 |
| face | `fa/face:1.0.0` | 无 | `/face-api/**` 经 nginx，验收容器直连 |
| agent | `fa/agent:1.0.0` | 无 | Streamlit，`/agent/` 经 nginx（去 X-Frame-Options） |
| mysql | `mysql:8.0` | 无 | 数据卷 `./data/mysql`（绑定目录，便于备份/迁移） |
| redis | `redis:7-alpine` | 无 | AOF 持久化到 `./data/redis` |
| e2e | `fa/face:1.0.0` | 无 | `profiles: [test]`，`docker compose up` 不会创建 |

**为什么绑定目录而不是命名卷**：备份脚本要能在宿主机直接 `tar` 走；命名卷要先进容器再拷，多一层且容易拷漏。代价是宿主机要对 `deploy/data` 有写权限。

**为什么 MinIO 从编排里去掉**：当前版本业务未接线原图归档（§13.3 是"加密后存 MinIO"，尚未实现上传路径）。留一个永远空闲的 MinIO 只会让冷启动多等一次健康检查、多一个要备份的卷。定义与卷保留在 compose 注释里，接线上传时再开。

## 3. 与文档的差异（需业主追认）

1. **服务数 6 而非 7**：MinIO 见上。
2. **`face_ro` 是库级 SELECT 而非表级**：初始化脚本在 mysqld 启动末尾执行，此时 Flyway 还没建表，表级 `GRANT` 会 1146 直接让 mysql 起不来。要收窄到表级，得在 Java 迁移后由应用执行一条 GRANT（列入遗留）。
3. **大屏 WebSocket 握手放行**：浏览器建立 WS 无法带 `Authorization` 头，JWT 只能走 query（契约如此）。`SecurityConfig` 对 `GET /api/v1/admin/sessions/*/live` 放行，鉴权由 `LiveWsConfig.authorized()` 完成（验签 + 角色 + 黑名单）。此前该路径被 `authenticated()` 拦住，**大屏从未真正连通**——这是 B5 遗留缺陷，B6 修掉。
4. **确认令牌 TTL 走 `CONFIRM_TTL_SEC` 环境变量**：契约写死 60s，测试用 61s 等待验证过期，不改默认值。

## 4. 部署步骤

```bash
cd deploy
cp .env.example .env
# 必改：MYSQL_*_PASSWORD / REDIS_PASSWORD / JWT_SECRET / INTERNAL_TOKEN /
#       SESSION_QR_SECRET / BOOTSTRAP_ADMIN_PASSWORD
./scripts/gen-tls.sh                 # 自签证书；生产替换 tls/server.crt|key
docker compose build
docker compose up -d
./scripts/wait-healthy.sh            # 或 ./scripts/verify-coldstart.sh 做计时验收
```

首次启动自动完成：Flyway 迁移（V1~V3）→ 建 15 张表 → 写入 33 条阈值种子 → 创建初始管理员（用户名/密码取 `.env`）。

## 6. 遗留问题

1. `face_ro` 权限仍是库级（原因见 §3.2）。
2. 原图归档未接线，MinIO 未部署（§3.1）。
3. 备份保留策略只在 `backup.sh` 里做了本地 7 天轮转，**没有异地副本**；生产需挂 cron + 异地同步。
4. `restore.sh` 恢复到独立库，验证完不会自动删库（避免误删），需人工执行打印出来的 `DROP DATABASE`。
5. 冷启动计时含镜像构建；若机器上无构建缓存（首次上机），耗时以 `--rebuild` 模式为准。
6. **改源码后必须 `docker compose build`**：三份 Dockerfile 都是 COPY 进镜像、不挂载源码，
   只 `up -d` 不会带上新代码（B6 排查 TTL 时被"env 已改但行为没变"多绕了几轮才定位）。
7. 面向生产部署的两个默认值记得改回：`ALLOW_ACTION_HINT=0`（验收环境开了 1）、
   `FA_CHALLENGE_TTL_SEC` 不设（走契约默认 60）。`deploy/.env.example` 已按生产口径写默认值。
