## 1. Gate 证据

### Gate 1 · 三端操作真实数据

同一场签到（`sessionId=2`，应到 1 人）在三处看到同一份数据：

| 端 | 观察到的内容 | 截图 |
|---|---|---|
| 管理端大屏 | 应到 1 / 已到 1 / 未到 0 / 签到率 100%，名单出现「E2E学生」 | `screenshots/admin-08-live.png` |
| 管理端考勤 | 2 条记录，状态「已签到」，比对 0.940 / 活体 0.02 | `screenshots/admin-09-attendance.png` |
| 移动端首页 | 同一场次，倒计时 113:03，「已签到」绿标 | `screenshots/mobile-m02-home.png` |

数据流走的是真链路：教师账号发起签到 → `session_expected` 冻结应到名单 → Agent 补签 →
`attendance` 落库 → 大屏轮询/WS 刷新 → 移动端 `/sessions/active` 读到同一条。

### Gate 2 · 写操作「预览→确认→执行→撤销」闭环

实测脚本（`.workbuddy/tmp/agent_e2e2.py`）16 项断言全通过：

```
[2] 预览：requiresConfirm=true, affectedCount=1, 有 confirmToken
[5] 执行：FA-0000, actionLogId=3
[7] 撤销：undone=true, 班级归档为 ARCHIVED（不物理删除，历史考勤可追溯）
```

撤销后再撤 → `FA-6005`；撤销别人的操作 → `FA-6004`；超过 30 分钟窗口 → `FA-6005`。

### Gate 3 · 令牌过期 / 参数篡改被拦截

## 3. 本轮修掉的真实缺陷

联调不是"点一遍确认页面能开"，下面这些是跑起来才暴露的：

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| 1 | 撤销返回 500 NPE | `create_class/course/session` 的主键是**执行时**才生成的，`undo` 却从 `params` 取 | `UndoFn` 补 `after` 快照，新建类工具从执行结果取 id |
| 2 | Agent 会话整段存不进去 | LangGraph 的 `checkpoint.ts` 是 ISO 字符串，代码直接 `float()` | 加 `_score()` 解析，失败退回当前时间 |
| 3 | 概览页 `HTTP-404` | `stats/overview`、`audit-logs`、`config` 三个契约端点后端从未实现 | 新建 `fa-system` 模块补齐 |
| 4 | 大屏"应到 0" | 签到是"签了才建 `attendance` 记录"，只查 `attendance` 看不到未签到的人 | 单场查询改以 `session_expected` 为基表 LEFT JOIN |
| 5 | 考勤行无法定位 | 同上，未签到的人没有 `attendance.id` | `Row.id` 允许 null，前端据此禁用"改状态" |
| 6 | 审计动作全是英文 | 前端映射写 `class.create`，后端实际写 `CLASS_CREATE` | 统一为后端格式，兼容旧写法 |
| 7 | 移动端首页白屏 | 契约 `sessions/active` 是"单条或 null"，前端当成数组 `.map()` | 改成 `ActiveSession \| null` |
| 8 | 概览趋势只有 1 天 | 默认区间取了 `today~today` | 默认近 7 天，`dateFrom/dateTo` 只影响趋势不影响今日卡片 |
| 9 | 配置页空白 | `sys_config` 表在 V1 只建表没种子 | `V3__seed_config.sql` 补 16 项 |
| 10 | 归档开关无效 | 前端传空串表示"全部"，被 `buildUrl` 过滤成"没传" | 显式传 `status=ALL` |

另外两处是**运行环境**问题，不是代码问题，但会反复咬人，已写进交接文档：

- 运行中的 fat jar 被后续 `mvn package` 覆盖 → `NoClassDefFoundError: ThrowableProxy`（把 jar 复制到独立路径再启动）
- `vite` 的依赖预构建要批量删缓存，沙箱拦删除会导致 dev server 起不来（改用 `vite preview` + 独立 `preview.proxy`）

## 6. 复现步骤

```bash
# 1. 中间件
docker start fa-mysql-gate          # MySQL @13306, root/gate
redis-server --port 6379 --save '' --appendonly no

# 2. 后端（用独立副本，避免被 mvn package 覆盖）
cp backend-java/fa-bootstrap/target/fa-bootstrap-*.jar /tmp/fa.jar
DB_PORT=13306 DB_NAME=fa_b5 java -jar /tmp/fa.jar

# 3. Agent 服务（必须 python -m，理由见 agent-service/README.md）
cd agent-service && JAVA_BASE_URL=http://127.0.0.1:8080 python -m streamlit run app/main.py --server.port=8501

# 4. 前端
cd admin-web && npx vite preview --port 5173
cd mobile-web && npx vite preview --port 5174

# 5. 账号
#   admin / Admin@12345       （管理员）
#   ETdd2dc4 / Teach@12345    （教师，发起签到必须用它）
#   E2Sdd2dc4 / Stud@12345    （学生）
```
