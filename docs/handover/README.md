# 工作包交接记录（Handover）

每个工作包收尾时必须有一份 `WP-xx.md`。**没有 handover 的工作包视为未完成**（项目文档 §16.4）。

## 命名

```
docs/handover/WP-00.md
docs/handover/WP-03.md
...
```

## 模板

```markdown
# WP-xx <名称>

- 批次：Bx
- 完成日期：YYYY-MM-DD
- 执行者：

## 变更清单

| 文件 / 目录 | 变更类型 | 说明 |
|---|---|---|
| | 新增 / 修改 / 删除 | |

## 接口实现对照

| 契约端点 | 实现位置 | 是否与契约一致 | 备注 |
|---|---|---|---|
| | | ✅ / ⚠️ | |

> 不一致的地方必须写清原因，并在 `docs/change-request/` 补 CR。

## 自测记录

```bash
# 命令 + 输出（贴真实输出，不要写「已通过」）
```

| 验收项 | 结果 | 证据 |
|---|---|---|
| | ✅ / ❌ | |

## 本包提交列表

| commit | 说明 |
|---|---|
| `abc1234` | feat(wp-xx): ... |

推送验证（三条都要为空或符合预期）：

```bash
git log origin/$(git branch --show-current)..HEAD --oneline   # 应为空
git status --porcelain                                        # 应为空
git log --oneline --grep="wp-xx" -i                           # 应有若干条
```
