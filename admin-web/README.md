# admin-web — 教师 / 管理员后台

按角色渲染菜单的后台前端。教师看自己授权范围内的班级与课程，管理员看全部 + 教师管理 + 审计。

## 页面

| 页面 | 说明 |
|---|---|
| 概览 | 今日签到率、待处理申诉 |
| 学生管理 | 列表、CSV 导入、人脸审核 |
| **班级管理** | 独立 CRUD，**表单里不得出现任何课程字段** |
| **课程管理** | 独立 CRUD，**表单里不得出现任何班级字段** |
| 发起签到 | 四步：选班级 → 选课程 → 设时长 → 确认「班级 × 课程」与应到人数 |
| 二维码大屏 | 班级名与课程名并列常驻、15 秒轮换、实时名单 |
| 考勤查询 | 按班级/课程/日期/状态筛选，内联改状态、导出 |
| 申诉处理 | 未处理优先 |
| 智能助手 | 对话 + **确认卡片**（字段级 diff、影响条数、倒计时、撤销） |
| 系统 | 审计日志、系统配置（仅 ADMIN） |

## 边界（不做什么）

- 不做安全边界：前端隐藏按钮只是体验，所有写接口后端二次校验。
- 不直接调用人脸服务，走 Java 的 `/api/v1/**`。

## 技术栈

Vue 3 + Vite + TypeScript + Element Plus + Pinia + ECharts。API 客户端由 `contracts/openapi/java-api.yaml` 生成。
